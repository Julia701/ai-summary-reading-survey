## 理论框架

研究以**社会交换理论**为主轴，把读者的阅读决策理解为对**成本**与**收益**的隐性核算：

```
AI 摘要介入
    ├── 概念一：阅读成本感知（时间 · 精力 · 机会成本）
    ├── 概念二：阅读收益感知（信息层收益 / 意义层收益）
    │              ↓ 权衡
    ├── 阅读决策：替代效应（摘要即终点） vs 互补效应（摘要＝筛书器）
    │              ↓
    └── 知识建构场景迁移：系统型 → 检索型 → 社交视听型
```

配套理论：认知负荷理论与认知卸载（解释"为什么人本能选省力的路"）、使用与满足与媒介替代/互补（解释"两类收益满足不同需求，未必互相替代"）、布迪厄文化资本（解释"为什么它仍不能被完全替代"）。

**核心论点**：AI 摘要几乎可以完全替代**信息层收益**，却难以替代**意义层收益**。因此"AI 会不会让人不读书"，取决于读者是冲着哪一层收益去读书的。

---

## 核心概念

- **阅读成本感知**（Perceived Reading Cost）：读者对完成一次完整阅读所需付出的时间、精力、注意力等资源的主观评估，及其相对替代方案（AI 摘要）的机会成本感知。
- **阅读收益感知**（Perceived Reading Value）：读者预期从完整阅读中获得的价值，分为
  - *功利性收益（信息层）*：知道这本书讲了什么
  - *建构性收益（意义层）*：形成自己的思考、深度理解、不可替代的体验
